# Data minimization and metrics

The CSV contains one fictional participant at example.invalid. The aggregate JSON contains fabricated numbers solely to illustrate report structure. Neither file is an operational record.

Use an approved private system for recipients and events. Agree purpose, privacy requirements, access, retention and deletion with the appropriate owners. This template does not prescribe a legal retention period.

Avoid passwords, session material, unnecessary identifiers and unrelated browsing information.

## Suggested measures for an approved exercise

- Reports through the approved channel divided by delivered messages.
- Time to first valid report, using a defined clock and cohort.
- Educational follow-up completion where appropriate and authorized.
- Delivery failures and collection gaps, reported separately.

Link scanning, mail security products, image preloading and duplicate events can distort open/click counts. State denominators, exclusions and uncertainty. An open event is not proof of compromise or learning.

The example contains 100 fabricated deliveries and 12 fabricated reports: 12% is arithmetic demonstration only, not a result achieved by the maintainer.
