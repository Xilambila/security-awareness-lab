# Planning and closure template

There are no campaign execution commands or real recipients in this repository.

## Before an operational exercise

1. Agree the learning objective, audience, exclusions, delivery window and accountable owner.
2. Obtain written authorization and align with security, privacy, legal, HR and compliance processes as applicable.
3. Define minimal data fields, access, retention, deletion and reporting rules in an approved private system.
4. Review content for accessibility, unnecessary pressure, sensitive themes and third-party rights.
5. Test with designated lab accounts. Validate access boundaries, limits, educational follow-up and the stop procedure.
6. Record go/no-go criteria and who can stop the exercise.

## Stop conditions

Stop and escalate if scope is exceeded, a real incident is suspected, sensitive data is submitted, infrastructure behaves unexpectedly or an authorized owner requests a stop. Use the approved response and evidence-handling process.

## Closure

Provide educational follow-up, report agreed aggregate observations, record limitations and improvement actions, remove temporary access and apply the approved retention policy. Avoid punitive individual reporting.

Approvals, recipients and operational evidence belong in a private system, never in this public repository.
